TAKE NOTE:

The populated_cleaned_macro_data is a shift to the original macroeconomic data. We moved monthly data forward ie january data is applied in february, Q1 data is applied in Q2. This is to ensure that we avoid look-ahead-bias. The january macro_data will be used to predict february stock. We cannot use february macro_data to predict february stock, because the data has not taken any effect yet. Same as Quarterly data. Daily data like foreign_reserves has immediate effect so no shifts done
